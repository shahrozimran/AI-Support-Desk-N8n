# AI Support Desk — n8n Automation

An AI-powered customer support automation workflow built using n8n and OpenRouter.

## Features
- Customer support request intake form
- AI-powered ticket classification
- Automatic priority assignment
- AI-generated response drafts
- Confidence-based escalation
- Human review queues
- HTML support report generation
- Manual testing with example support tickets

- n8n

- JavaScript
- HTTP Requests
- HTML/CSS

## How to Run
1. Install or open an n8n instance.
2. Import `AI_Support_Desk_GitHub_Sanitized.json`.
3. Configure your own OpenRouter Header Auth credential.
4. Run the demo trigger or test the support intake form.
5. Inspect the generated triage results and report.

## Note
API credentials are not included in this repository. All AI-generated customer replies remain drafts for human review.
